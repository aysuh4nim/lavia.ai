# lavia.ai

Lavia artık konuşaibiliyor (:

## Değişiklikler (Changelog)

- Ses sorunu çözüldü — uygulamadaki ses oynatma ve senkronizasyon hataları giderildi.
- Sesler daha gerçekçi hale getirildi — konuşma sentezi (TTS) kalitesi arttırıldı ve doğal tonlar eklendi.
- Supx.ai API entegrasyonu eklendi — ses üretimi ve konuşma özellikleri için supx.ai kullanılıyor.
- Artık konuşabiliyor — kullanıcı ile sesli diyalog destekleniyor (mikrofon/giriş ve hoparlör/çıkış).

## Nasıl Denenir

- projeyi ayağa kaldırmak için önce `npm install` komutunu kullanın ardından `server.js`'i çalıştırın (örn. `node server.js`).
